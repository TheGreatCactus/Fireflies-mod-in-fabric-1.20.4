Fireflies Mod (Fabric)
A Fabric modification that adds interactive swarms of fireflies to the game world. Players can catch them, store them in bottles as throwable item.

Features & Mechanics
Firefly Swarms (Entities): New custom entities spawning in the world that represent firefly swarms with dynamic sizes.

Catching Mechanics: Right-clicking (RMB) on a swarm with an empty glass bottle captures the fireflies. This action visibly reduces the overall size of the swarm in the world.

New Item: Upon successfully catching the insects, the player receives a "Fireflies in a bottle" item.

Throwing: The "Fireflies in a bottle" item can be used by right-clicking, which throws the bottle.
